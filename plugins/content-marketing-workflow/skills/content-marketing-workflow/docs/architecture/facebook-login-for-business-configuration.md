# Facebook Login for Business configuration for Page token onboarding

Date: 2026-09-04
Status: normative current onboarding sub-contract - live validated

## Purpose

Defines the Meta configuration required between Page permissions being ready and Graph API Explorer being able to generate the bootstrap User Access Token used to derive the final Page credential.

Concrete application/configuration/Page names and IDs belong to the active user profile, not this generic contract.

## Why this configuration is required

If Graph API Explorer has the intended Meta app selected but requesting a User Access Token reports no available configuration, use:

```text
Meta app dashboard
-> Facebook Login for Business
-> Configurations
-> Créer la configuration
```

Do not broaden permissions or recreate the Meta app merely to solve this missing configuration.

## Profile-owned values

Read/write under the active project Facebook connection:

```text
meta_app_id
login_configuration_name
login_configuration_id
remote_id
remote_name
scopes
```

Generic schema: `docs/architecture/schemas/user-profile.schema.json`.

## Validated generic configuration

```text
Configuration name: a clear Page-publication label chosen/stored for this user
Login variant: General
Token type: User Access Token
Asset scope: current Pages only
```

The configuration ID is non-secret user/project metadata and may be persisted in the user profile. Tokens/App Secret are secret.

### Permissions

Select only the adapter requirements:

```text
pages_show_list
pages_read_engagement
pages_manage_posts
```

Do not manually add `business_management` merely because Meta displays it as ready through a use case; the Bridge does not require it.

## Configuration wizard

Validated wizard sequence:

```text
Nom
-> Variante de connexion
-> Token d’accès
-> Éléments
-> Autorisations
```

Validated choices:

```text
Nom: <profile login_configuration_name>
Variante de connexion: General
Token d’accès: Token d’accès utilisateur
Éléments: may be unavailable for this token type
Autorisations:
  - pages_show_list
  - pages_read_engagement
  - pages_manage_posts
```

If Meta disables a system-user token option because the app is not associated with a Business Portfolio, do not create a Business Portfolio merely to unlock it for a simple own-Page onboarding unless a later requirement justifies that architecture.

## Graph API Explorer handoff

After the configuration exists, return to Graph API Explorer and require:

```text
Application Meta: <profile Meta application>
Configuration: <profile login_configuration_name>
Type de token: Token d’accès utilisateur
Permissions:
  - pages_show_list
  - pages_read_engagement
  - pages_manage_posts
```

Then generate the User Access Token.

During Meta consent:

```text
verify correct personal Facebook administrator account
-> choose current Pages only
-> select exactly the intended profile Page
-> review requested Page capabilities
-> save/continue
```

Persist the exact verified API Page ID/name to user data. Never hard-code them in this contract.

## Token semantics

The User Access Token generated by Graph API Explorer is bootstrap only. Inspect validity, scopes and expiry before deriving a production credential.

A short-lived User token must never be installed in WordPress.

If it expires, do not recreate this configuration. Generate a fresh User token using the existing profile configuration, reverify the exact Page/tasks and continue the token-provisioning contract.

## Resume behavior

Persist the configuration as complete in user data once created successfully.

Do not reopen this wizard on routine credential renewal unless Meta reports the configuration missing/invalid or the user intentionally replaces the app.

Credential rotation resumes at:

```text
Generate Access Token
-> verify /me/accounts
-> Étendre le token d'accès
-> derive exact Page token
-> debugger validation
-> WordPress handoff
```

## Security

Never persist or expose raw User Access Tokens, Page Access Tokens, App Secret or client token. Once any token exists, screenshots used for guidance must hide its raw value.
